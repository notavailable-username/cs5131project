# Motion-Aware Few-Shot Object Detection System

## Overview
This project implements an integrated motion-aware few-shot object detection system that combines motion detection with few-shot learning for efficient object detection and classification.

## Features
- Motion detection to identify moving objects in video streams
- Few-shot learning ensemble for object classification with minimal training data
- YOLO-based model for object detection and training
- Interactive GUI for annotation, visualization, and model training
- Command-line interface for batch processing and model training

## Installation
1. Clone the repository
2. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```
3. Make sure you have PyQt6 and OpenCV properly installed on your system
